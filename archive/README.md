# Archivo de Typers

`typers-nestjs/` conserva los 396 archivos de la demo NestJS desarrollada el 15 de septiembre de 2026, incluidos los cambios que estaban sin commit. El manifiesto identifica el commit de origen y el SHA-256 de cada archivo. No contiene dependencias instaladas, secretos locales, builds ni la base de datos Git.

La copia es histórica, no un workspace activo ni parte de las suites del compilador. Sus instrucciones de continuación y sus resultados pertenecen a la fecha original. Typers está en pausa por decisión del titular del 27 de septiembre de 2026.

## Recuperación

Para reproducir el laboratorio en el futuro, copiar `typers-nestjs/` a una carpeta hermana de un checkout llamado `typers`. Sus scripts y tarballs usan esa relación. Seguir después su README y reconstruir las dependencias desde los lockfiles. No ejecutar los scripts directamente dentro de este archivo: las rutas históricas no apuntan al compilador desde aquí. La sintaxis experimental exige el compilador Typers.
